Journey to the East

Journey to the East is a Sanskrit-learning game (though the name is inspired by a Chinese novel), where each level teaches a different concept in Sanskrit, with each level building up to the final level, where the user tries to translate audio.

Each level also has a lesson associated with it that can be accessed by hitting the light bulb in the corner.

Check out the game here: https://sara-k03.github.io/journey-to-the-east/#/

GitHub Link: https://github.com/sara-k03/journey-to-the-east

All lessons have been either vetted or inspired by Rishi Gopinath, my friend and Sanskrit tutor.

I. Concept

Each level is named after a different Indian empire (with the exception of the first and last levels). Each progressive level takes you backwards in chronology, while the concepts get increasingly difficult.

Below is a table of the levels and what they tentatively will cover. Currently, I have only developed Levels 1 and 2.

Level Concept Format
Republic Learn the consonants and vowels in Devanagari. This level is just a typical quiz game where the user needs to learn all the vowels and consonants.
Maratha Learn the most widely used combinations of the consonants and vowels (in Devanagari). Level 2 drills the different Devanagari combinations using a falling character game. The user has to transcribe different Devanagari combinations before they fall through the bottom of the screen.
Vijayanagara

Read singular words in Sanskrit. This will include avyayāḥ (indeclinables), common verbs forms, common nouns, common philosophical concepts, etc.

The user just needs to transcribe the word from IAST to Devanagari in this level. The translation will be provided after the user gets it right (so they can learn).

III. Code Structure

This game is currently front-end only, and player progress data is stored locally (it does not sync across devices or browsers). A proper backend will be designed after the frontend of the game has been fleshed out. The game is also a single-page React app built with Vite and deployed to GitHub Pages.

├── vite.config.js (Sets the /journey-to-the-east/ base path for GitHub Pages)
├── .github/workflows/deploy.yml (Builds and deploys to GitHub Pages on every push to main)
├── background-images/ (Background photos; the site uses the *-web.jpg copies and raigad-fort.jpg)

└── src/

How a level fits together

Every level is made of the same few pieces: an entry in src/levels.js, a set of questions in src/data/, a lesson in src/lessons/, and a page in src/pages/. The page hands the questions and lesson to one of the shared game components in src/components/, which handles the actual gameplay. This means that a new level can reuse an existing game format just by supplying new questions and a new lesson. Each page also gets its own route in src/App.jsx. Levels that aren’t playable yet show as “Coming soon” on the homepage.

Progress is tracked per level and saved in localStorage. What counts toward progress depends on the level’s format, but in general, the player only earns credit for answers they get right on their own.

Level 1 (Republic): A Simple Quiz Game

The player sees one Devanāgarī letter at a time and types it in IAST, using either their keyboard or the on-screen buttons for characters like ā, ṭ, and ś. After checking, the game shows whether the answer was right (and the correct transcription if it wasn’t), then moves on to the next letter.

The question set in src/data/republic.js has 48 letters: 14 vowels (svarāḥ) and 34 consonants (vyañjanāḥ). Letters the player hasn’t gotten right yet are picked first, and the same letter is never shown twice in a row. The lesson opens at the start of the level and can be reopened with the light bulb button, but opening it mid-question means that question won’t count toward progress.

Level 2 (Maratha): The Falling Akṣara Game

Akṣaras fall one at a time, and the player types each one in IAST before it hits the ground. An answer clears as soon as it matches.

  • Game mode: The user has 3 lives, and each akṣara falls a little faster than the last (8 seconds at first, down to 3). Only game mode counts toward progress. The best score is saved under the jtte-high-scores key.
  • Practice mode: Practice mode doesn’t have a cap on the number of lives, but it also doesn’t contribute to the progress. The player picks the akṣaras (all, consonant + mātrā, or conjuncts) and a fixed speed, and can reveal the answer.

The pool is built in src/data/maratha.js: 33 consonants and 191 conjuncts, each in 15 forms (the inherent a, 11 mātrās, anusvāra, visarga, and virāma), for 3,360 akṣaras. To add or remove a conjunct, edit its line in conjunctGroups. The progress bar counts forms, and a group (one consonant or conjunct) is complete once all 15 of its forms are done. The lesson opens automatically only on the first visit (jtte-lessons-seen).
