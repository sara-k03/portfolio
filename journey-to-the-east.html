Journey to the East

Journey to the East is a Sanskrit-learning game (though the name is inspired by a Chinese novel), where each level teaches a different concept in Sanskrit, with each level building up to the final level, where the user tries to translate audio.

Each level also has a lesson associated with it that can be accessed by hitting the light bulb in the corner.

Check out the game here: https://sara-k03.github.io/journey-to-the-east/#/

GitHub Link: https://github.com/sara-k03/journey-to-the-east

All lessons have been either vetted or inspired by Rishi Gopinath, my friend and Sanskrit tutor.

I. Concept

Each level is named after a different Indian empire (with the exception of the first and last levels). Each progressive level takes you backwards in chronology, while the concepts get increasingly difficult.

Below is a table of the levels and what they tentatively will cover. Currently, I have only developed Level 1.

Level Concept Format
Republic Learn the consonants and vowels in Devanagari. This level is just a typical quiz game where the user needs to learn all the vowels and consonants.
Maratha Learn all the possible combinations of the consonants and vowels (in Devanagari). TBA
Vijayanagara

Read singular words in Sanskrit. This will include avyayāḥ (indeclinables), common verbs forms, common nouns, common philosophical concepts, etc.

The user just needs to transcribe the word from IAST to Devanagari in this level. The translation will be provided after the user gets it right (so they can learn).

 TBA
Chola This will be similar to the last level, but the user will need to translate the word. TBA
Rashtrakuta This level will teach the most essential shabdarupani (noun forms). The shabdarupani that will be used is to be decided. TBA
Chalukya This level will teach the most essential lakāraḥ (verb conjugations). Which lakāraḥ will be used is to be decided. TBA
Kamarupa The user will transcribe simple sentences from IAST to Devanagari (like the Vijayanagara level, but with sentences rather than words). TBA
Gupta Learn the Sanskrit sandhi rules. TBA
Kushan The user will translate simple sentences (like the Chola level, but with sentences rather than words). TBA
Maurya Transcribe verses from actual Sanskrit texts from Devanagari to IAST. TBA
Kuru Translate verses from actual Sanskrit texts. TBA
Sarasvati Translating actual Sanskrit audio into English. TBA

There may also be possible bonus levels to learn other Indian scripts.

III. Code Structure

This game is currently front-end only, and player progress data is stored locally (it does not sync across devices or browsers). A proper backend will be designed after the frontend of the game has been fleshed out. The game is also a single-page React app built with Vite and deployed to GitHub Pages.

├── index.html (Vite entry HTML; loads Noto Serif Devanagari)
├── vite.config.js (Sets the /journey-to-the-east/ base path for GitHub Pages)
├── .github/workflows/deploy.yml (Builds and deploys to GitHub Pages on every push to main)
├── background-images/ (Background photos plus the resized *-web.jpg copies the site uses)
├── fonts/jaini/ (Jaini font files and license)
└── src/
    ├── main.jsx (Mounts <App /> and imports global styles)
    ├── App.jsx (Routes; uses HashRouter so deep links work on GitHub Pages)
    ├── levels.js (List of all 12 levels: name, description, route, question count, background)
    ├── progress.js (Reads/writes player progress in localStorage)
    ├── styles.css (All styling)
    ├── pages/
    │   ├── Home.jsx (Level select screen with a progress bar per level)
    │   └── Republic.jsx (Level 1 page)
    ├── components/
    │   ├── TranscriptionLevel.jsx (Reusable quiz: show Devanāgarī, player types IAST)
    │   ├── IastKeys.jsx (On-screen buttons for IAST characters such as ā, ṭ, ś)
    │   ├── LessonDialog.jsx (Modal that shows a level's lesson)
    │   ├── LessonButton.jsx (Light bulb button that reopens the lesson)
    │   └── ProgressBar.jsx
    ├── data/
    │   └── republic.js (Level 1 questions)
    └── lessons/
        └── RepublicLesson.jsx (Level 1 lesson content)

How a level fits together

Each playable level has an entry in src/levels.js with a path, a question set in src/data/, a lesson in src/lessons/, and a page in src/pages/ that passes those into a shared level component (currently TranscriptionLevel). The page’s route is registered in src/App.jsx. Levels without a path show as “Coming soon” on the homepage.

A question counts toward progress only if the player answers it correctly without opening the lesson first. Progress is saved per level in localStorage under the jtte-progress key.
