from collections import defaultdict

    class Solution(object):
        def groupAnagrams(self, strs):
            # dictionary where default value is an empty list
            anagrams = defaultdict(list)
            # loop, have to cast sorted s to str because it returns a list by default
            for s in strs:
                anagrams[str(sorted(s))].append(s)
            # have to cast return value to a list, otherwise it returns a different sort of object
            return list(anagrams.values())

Source: LeetCode

Pattern: Frequency Counting

Data Structure: Hash Map

Time: O(n * k log k), where n is number of strings and k is average string length

Space: O(nk)

Comments:

  • The time complexity is O(n * k log k) because the loop runs n times and a sorting function is performed in each iteration which is k log k.
  • The space complexity is O(nk) because the dictionary/hash map stores n strings that each have an average of k characters.
