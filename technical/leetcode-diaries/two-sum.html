class Solution(object):
        def twoSum(self, nums, target):

            # dictionary of value (key) and index (value)
            seen = {}

            # enumerate returns two values: the index and the value, eliminates need for a counter
            for i, val in enumerate(nums):
                # required number to hit target
                required = target - val

                # have we already seen this?
                if required in seen.keys():
                    return [seen[required], i]

                # adding to seen dictionary
                seen[val] = i

Source: LeetCode

Pattern: Seen Elements

Data Structure: Hash Map

Time: O(n)

Space: O(n)

Comments:

  • The time complexity is O(n) because there is only one for loop and only O(1) operations are performed inside the for loop.
  • The space complexity is O(n) because seen grows by one element per iteration.
