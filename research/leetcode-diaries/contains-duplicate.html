class Solution(object):
        def containsDuplicate(self, nums):
            seen = set()

            for n in nums:
                if n in seen:
                    return True
                seen.add(n)

            return False

Source: LeetCode

Pattern: Seen Elements

Data Structure: Hash Map

Time: O(n)

Space: O(n)

Comments:

  • This is considered the simplest of the Seen Elements pattern, where you keep track of elements you've encountered so you can determine whether or not you've encountered them before in the future.
  • The time complexity is O(n) because adding/searching a set is O(1) due to the underlying structure being a hash table. Since we perform a search of the set (and possibly an addition to the set) for every element in the array in the worst case, the time complexity is O(n).
  • The space complexity is also O(n) because, in the worst case, the data structure can grow proportionally to the size of the input.
