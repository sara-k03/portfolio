class Solution(object):
    def isAnagram(self, s, t):

        # base case
        if len(s) != len(t):
            return False

        # dictionary
        counts = {}

        # syntax: dictionary.get(key, default_value), default_value ensures there's no error
        for char in s:
            counts[char] = counts.get(char, 0) + 1

        for char in t:
            counts[char] = counts.get(char, 0) - 1

        for v in counts.values():
            if not v == 0:
                return False

        return True

Source: LeetCode

Pattern: Frequency Counting

Data Structure: Hash Map

Time: O(n)

Space: O(n)

Comments:

  • This problem is considered the simplest of the Frequency Counting pattern. In terms of code, my original solution was actually simpler than the one above. It was one line that is sorted(t) == sorted(s). However, this is technically n log n because of the sorting. Learning the frequency counting pattern also provides the basis for future problems.
  • The time complexity is O(n) because each for loop, which iterates through n characters, accesses the dictionary/hash table which is O(1).
  • The space complexity is O(n) because the dictionary can contain up to n distinct characters in the worst case.
