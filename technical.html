Measuring Viscosity

Updated September 2026

The primary goal of this experimental physics capstone project is to use a confocal microscope to measure the viscosity of a solution using a confocal microscope. An image analysis pipeline will be used to track the movement of beads in the solution. This tracking data will be used to measure the diffusion coefficient of the beads, which will then be used to measure the viscosity. These results will then be compared to results obtained from a rheometer.
